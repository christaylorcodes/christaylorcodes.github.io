description: |
  Enterprise-focused PowerShell module providing comprehensive programmatic access to the Webroot Unity REST API for endpoint security management across multi-tenant MSP environments. Automates threat detection retrieval with advanced filtering capabilities to identify compromised endpoints, active infections, and policy violations requiring immediate attention. Manages security policy deployment including antivirus definitions, web filtering rules, and application control configurations across customer organizations with inheritance and override support. Monitors deployment status across thousands of endpoints to identify outdated agents, failed updates, and unprotected systems requiring remediation.

  Generates security reporting including infection trends, threat statistics, and compliance metrics suitable for executive dashboards and customer-facing quarterly business reviews. Enables seamless integration of Webroot security data into ConnectWise Manage or other PSA systems for automatic ticket creation when threats are detected or policies are violated. Provides real-time alert processing that can trigger automated remediation workflows including agent reinstallation, policy enforcement, or escalation to security teams. Supports dashboard visualization by exposing security metrics through PowerShell objects that integrate with Grafana, Power BI, or custom reporting platforms.

  Eliminates manual API construction, authentication management, and response parsing that typically requires extensive development effort for each integration scenario. Features consistent error handling with detailed diagnostic information to accelerate troubleshooting when API responses indicate failure conditions. Supports bulk operations for efficient management of large MSP customer bases with hundreds of thousands of protected endpoints.
