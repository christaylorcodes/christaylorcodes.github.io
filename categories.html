Category Filter Samples

Showcase of category filter button styles used in the blog, including different color variations from the Oceanic palette for filtering and selection interfaces.

Standard Filter Buttons

Default filter buttons using cyan theme. Click buttons to see active state.

Color Variations

Five filter button variations using different colors from the Oceanic palette. Each can be used for different filtering contexts or to match specific UI themes.

Cyan (Default)

Color: #06b6d4 | Usage: Primary filtering, blog categories, main content filters

Emerald Green

Color: #10b981 | Usage: Success states, positive filters, active selections

Amber

Color: #f59e0b | Usage: Warning states, in-progress filters, pending items

Orange

Color: #ea580c | Usage: Priority filters, important categories, urgent items

Red

Color: #dc2626 | Usage: Error states, blocked items, deprecated content

Interactive States

Filter buttons support three states: default, hover, and active. Click to toggle active state, hover to see transitions.

HTML Usage

<!-- Standard filter buttons -->
<div class="filter-buttons">
    <button class="filter-btn active">All</button>
    <button class="filter-btn">Category <span class="filter-count">5</span></button>
</div>

<!-- Color variations -->
<button class="filter-btn filter-cyan active">Cyan</button>
<button class="filter-btn filter-emerald">Emerald</button>
<button class="filter-btn filter-amber">Amber</button>
<button class="filter-btn filter-orange">Orange</button>
<button class="filter-btn filter-red">Red</button>
